# MEDLANZ Pharmacy Website

Premium Next.js website for **MEDLANZ Pharmacy** in Hor Al Anz, Deira, Dubai, UAE.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production URL

Set your real domain in `.env.local`:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

Or update the fallback in `lib/config.ts`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — start production server
- `npm run lint` — ESLint

## Business details

All company information lives in `lib/config.ts` for easy updates.
